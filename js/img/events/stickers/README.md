# Event stickers

These unmodified SVG illustrations are by **OpenMoji**, the open-source emoji
and icon project by HfG Schwäbisch Gmünd, Benedikt Groß, Daniel Utz, students
and external contributors.

- Source: https://github.com/hfg-gmuend/openmoji
- Release: `openmoji@16.0.0`, downloaded from https://unpkg.com/openmoji@16.0.0/color/svg/
- Graphics license: **CC BY-SA 4.0**, https://creativecommons.org/licenses/by-sa/4.0/
- Full upstream license: [LICENSE.txt](LICENSE.txt)
- Download inventory: [download-list.json](download-list.json)
- Refresh command from the project root: `python scripts/fetch-event-stickers.py`

`js/event-media-data.js` maps each event and choice to a sticker. Images are
stored locally; the game makes no requests to an external image service.
OpenMoji attribution and the graphics license are retained in this directory.
