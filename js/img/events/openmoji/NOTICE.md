# OpenMoji

Artwork: OpenMoji, the open-source emoji and icon project by HfG Schwäbisch
Gmünd and contributors. Official version: 17.0.0.

Source: https://github.com/hfg-gmuend/openmoji/releases/tag/17.0.0
Official package: https://registry.npmjs.org/openmoji/-/openmoji-17.0.0.tgz
License: Creative Commons Attribution-ShareAlike 4.0 International.
https://creativecommons.org/licenses/by-sa/4.0/

`color/svg/` and `black/svg/` contain the complete, unmodified original SVGs.
`openmoji.json` contains the official metadata. The full license is LICENSE.txt.
The package integrity and source archive hash are recorded by sync-openmoji.py.

`animated/svg/` is an adaptation made for this game: SVG transforms, blinking
and opacity animation have been added to the original artwork. The icon paths,
palette and style remain OpenMoji. These adaptations use CC BY-SA 4.0 as well.
They are game adaptations, not an official animated OpenMoji distribution.
