# Life Again cho Windows

`npm run desktop:build` tạo `output/windows-release/LifeAgain-Windows-x64.exe` và tệp SHA-256 bên cạnh. Cần Internet lúc build để tải runtime/công cụ đóng gói và font; người chơi không cần cài Node.js, Chrome hoặc Edge.

Người chơi Windows x64 tải một file `.exe`, lưu vào thư mục riêng rồi bấm đúp để chơi. Đây là bản portable, không cần quyền quản trị hoặc trình cài đặt. Mỗi bản phát hành chứa toàn bộ mã game, hình ảnh và font. Từ bản 1.0.1, game tự kiểm tra GitHub Releases khi mở và mỗi 6 giờ, tải bản Windows mới trong nền rồi hỏi trước khi khởi động lại để thay EXE. Có thể chọn Life Again → Kiểm tra cập nhật. Tệp tải về phải đúng kích thước và SHA-256; tệp tải dở hoặc sai mã bị loại bỏ. Chọn Để sau vẫn tiếp tục chơi; lần mở sau dùng lại tệp đã xác minh. Mất mạng vẫn chơi offline bình thường. Thư mục chứa EXE cần có quyền ghi.

Bản 1.0.0 chưa có updater: người chơi cần tải và thay EXE một lần để lên 1.0.1. Sau đó các bản mới sẽ cập nhật từ release công khai mới nhất có tag `windows-vX.Y.Z` cùng hai asset `LifeAgain-Windows-x64.exe` và `LifeAgain-Windows-x64.exe.sha256`. Tăng version trong package.json trước mỗi lần phát hành; chạy `npm run desktop:build`, `npm run test:desktop:updater`, `npm run test:desktop` và `npm run test:desktop:portable`, rồi phát hành cả hai tệp và đặt release là latest. Không thay asset của release đã công khai.

Bản lưu dùng profile `%APPDATA%\LifeAgain` và origin cố định `lifeagain://game.lifeagain`, độc lập với thư mục chứa file `.exe`. Không xóa thư mục profile nếu muốn giữ cuộc đời. Bản lưu trên web không tự chuyển sang Windows; dùng Chuyển thiết bị → xuất/nhập tệp sao lưu. Mã chuyển trực tuyến kết nối hai API chuyển dữ liệu của website chính thức khi người chơi yêu cầu.

`npm run test:desktop` chạy bản đã đóng gói trong profile thử riêng, chặn mạng để tạo nhân vật, đóng rồi mở lại để tiếp tục bản lưu. Kiểm tra đường dẫn tài nguyên, font ngoại tuyến, sandbox và giới hạn truy cập tệp. `npm run test:desktop:portable` chạy chính file phân phối để xác nhận tự giải nén và mở game. Giấy phép font đi kèm trong gói `game/desktop-fonts`. Có thể đặt `PLAYWRIGHT_PATH` tới thư viện Playwright đã cài; mặc định dùng runtime Codex trên máy phát triển hiện tại.

Để phân phối trên website, tải `.exe` và `.sha256` lên GitHub Releases hoặc máy chủ tải tệp, rồi dùng URL của file phát hành cho nút tải Windows. Không đưa file nhị phân lớn vào Git. Bản build local chưa được ký Authenticode; phát hành có ký số cần chứng thư của nhà phát triển. Không hướng dẫn người chơi tắt bảo vệ Windows.

Electron dùng custom protocol phục vụ file từ gói cục bộ, không mở cổng máy chủ. Renderer không có Node.js, không có preload/IPC, bật sandbox và context isolation. Updater chạy riêng trong main process, chỉ lấy thông tin release từ repository chính thức qua HTTPS và không mở API tải/chạy tệp cho renderer. Trình hỗ trợ PowerShell ẩn chờ game đóng bình thường, kiểm tra lại SHA-256, giữ EXE cũ để khôi phục nếu bước thay/chạy bản mới gặp lỗi; không xóa hay di chuyển profile bản lưu. Liên kết HTTPS bên ngoài mở ở trình duyệt; các scheme khác bị chặn. Cấu hình theo [hướng dẫn bảo mật Electron](https://www.electronjs.org/docs/latest/tutorial/security) và [custom protocol](https://www.electronjs.org/docs/latest/api/protocol).
